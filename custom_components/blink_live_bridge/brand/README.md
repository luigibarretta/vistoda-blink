# Vistoda Blink integration icon

`icon.png` (256 px) and `icon@2x.png` (512 px) are the Vistoda family icon,
the same artwork as `vistoda-home-assistant`. It represents Vistoda, not Blink.

Home Assistant 2026.3+ serves this local asset through its authenticated
brands API, and HACS accepts it in place of a brands-repository entry. See the
[Home Assistant brand image contract](https://developers.home-assistant.io/docs/core/integration/brand_images/).
